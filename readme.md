# Nourish

A responsive healthy-food discovery website built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to use it locally. Netlify publishes the static project directly without a build step.

The home page includes category filters, ingredient search, sorting, pagination, recipe dialogs, session-only saved recipes, embedded YouTube cooking tutorials, and calorie, macro, BMI, healthy-weight, and BMR calculators.

The catalog contains 420 ingredient combinations defined in `fixtures.js`. Instructions are assembled from the chosen protein, base, and seasoning. Nutrition is approximate, photos are serving inspiration, and embedded tutorials teach general techniques rather than each exact dish. Photos load from Unsplash; fonts and videos require an internet connection. YouTube availability depends on the creator and viewer region.

See PLAN.md for the editorial roadmap, including verified recipe-specific videos and reviewed nutrition.
